# Source Basis

This lab is based on the project security route combining:

- IBM RACF administration concepts: users, groups, profiles, access lists, UACC, and SETROPTS refresh.
- Dattani mainframe security practice: prefer role/group-based administration and avoid unmanaged individual access entries.
- Prior project labs H7–H10: creation of a non-privileged test identity, real access testing, violation evidence, and temporary access remediation.
