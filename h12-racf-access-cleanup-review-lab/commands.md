# Commands

## Inventory

```text
SEARCH CLASS(DATASET) MASK(IBMUSER.SECLAB*)
LISTDSD DA('IBMUSER.SECLAB.PUBLIC.*') ALL
LISTDSD DA('IBMUSER.SECLAB.PRIVATE.*') ALL
LISTDSD DA('IBMUSER.SECLAB.GRANTED.*') ALL
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL
LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
LISTDSD DA('IBMUSER.SECLAB.GROUP.*') ALL
```

## USER2 review

```text
LISTUSER USER2
```

## Cleanup

```text
LISTDSD DA('IBMUSER.SECLAB.GRANTED.*') ALL
PERMIT 'IBMUSER.SECLAB.GRANTED.*' CLASS(DATASET) ID(USER2) DELETE
SETROPTS GENERIC(DATASET) REFRESH
LISTDSD DA('IBMUSER.SECLAB.GRANTED.*') ALL
```

## Functional verification with H7USER

From the `H7USER` session:

```text
Browse IBMUSER.SECLAB.GRANTED.DATA
Browse IBMUSER.SECLAB.PRIVATE.DATA
```

Expected result:

```text
IBMUSER.SECLAB.GRANTED.DATA -> permitted
IBMUSER.SECLAB.PRIVATE.DATA -> denied
```

## Group-profile cleanup verification

```text
LISTDSD DA('IBMUSER.SECLAB.GROUP.*') ALL
PERMIT 'IBMUSER.SECLAB.GROUP.*' CLASS(DATASET) ID(H7GRP) DELETE
SETROPTS GENERIC(DATASET) REFRESH
LISTDSD DA('IBMUSER.SECLAB.GROUP.*') ALL
```

Only run the `PERMIT ... DELETE` command if `H7GRP` is still present in the access list.
