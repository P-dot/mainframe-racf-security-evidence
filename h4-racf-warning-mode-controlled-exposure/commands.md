# Commands

## Dataset allocation / validation

```text
ALLOC DATASET('IBMUSER.SECLAB.WARNING.DATA') NEW CATALOG UNIT(SYSDA) SPACE(1,1) TRACKS DSORG(PS) RECFM(F B) LRECL(80) BLKSIZE(800)

LISTCAT ENT('IBMUSER.SECLAB.WARNING.DATA') ALL
```

## Create closed profile

```text
ADDSD 'IBMUSER.SECLAB.WARNING.*' UACC(NONE)

LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
```

## Enable WARNING mode

```text
ALTDSD 'IBMUSER.SECLAB.WARNING.*' WARNING

LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
```

## Add auditing

```text
ALTDSD 'IBMUSER.SECLAB.WARNING.*' AUDIT(ALL(READ))

LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
```

## Disable WARNING mode

```text
ALTDSD 'IBMUSER.SECLAB.WARNING.*' NOWARNING

LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
```

## Refresh generic DATASET profiles

```text
SETROPTS GENERIC(DATASET) REFRESH
```

## Final comparison

```text
LISTDSD DA('IBMUSER.SECLAB.PUBLIC.*') ALL
LISTDSD DA('IBMUSER.SECLAB.PRIVATE.*') ALL
LISTDSD DA('IBMUSER.SECLAB.GRANTED.*') ALL
LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
```
