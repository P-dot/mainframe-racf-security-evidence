# Commands Used

## Dataset creation

```text
ALLOC DATASET('IBMUSER.SECLAB.AUDIT.DATA') NEW CATALOG UNIT(SYSDA) SPACE(1,1) TRACKS DSORG(PS) RECFM(F B) LRECL(80) BLKSIZE(800)
LISTCAT ENT('IBMUSER.SECLAB.AUDIT.DATA') ALL
```

## RACF profile creation

```text
ADDSD 'IBMUSER.SECLAB.AUDIT.*' UACC(NONE)
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL
```

## Audit settings

```text
ALTDSD 'IBMUSER.SECLAB.AUDIT.*' AUDIT(FAILURES(READ))
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL

ALTDSD 'IBMUSER.SECLAB.AUDIT.*' AUDIT(ALL(READ))
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL

ALTDSD 'IBMUSER.SECLAB.AUDIT.*' AUDIT(FAILURES(READ))
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL
```

## Refresh

```text
SETROPTS GENERIC(DATASET) REFRESH
```

## SMF context

From SDSF LOG or operator command input:

```text
/D SMF
```

## Final sandbox comparison

```text
LISTDSD DA('IBMUSER.SECLAB.PUBLIC.*') ALL
LISTDSD DA('IBMUSER.SECLAB.PRIVATE.*') ALL
LISTDSD DA('IBMUSER.SECLAB.GRANTED.*') ALL
LISTDSD DA('IBMUSER.SECLAB.WARNING.*') ALL
LISTDSD DA('IBMUSER.SECLAB.AUDIT.*') ALL
```
