# Source Basis

This lab is based on the user's H7 evidence screenshots and the established RACF sandbox progression:

- H1: safe dataset profiles
- H2: UACC exposure
- H3: PERMIT and least privilege
- H4: WARNING mode
- H5: AUDIT readiness
- H6: Health Checker class activation baseline
- H7: controlled test identity

The purpose is to enable realistic access testing without using an overpowered administrative account.
