# GitHub upload commands

From Git Bash after extracting this folder into your repository:

```bash
cd /c/Carrera_Ciberseguridad/06_Portfolio_GitHub/mainframe-racf-security-evidence

git status
git add lab-09-y-10-zfs-saf-controls-review
git commit -m "Add combined Lab 09 and 10 zFS and SAF controls review"
git push
```

If you downloaded the ZIP, first unzip it into the repository root so the folder appears as:

```text
mainframe-racf-security-evidence/lab-09-y-10-zfs-saf-controls-review
```
