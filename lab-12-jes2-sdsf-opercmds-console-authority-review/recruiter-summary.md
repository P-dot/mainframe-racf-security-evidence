# Recruiter Summary

Performed a JES2, SDSF and RACF operational authority review on an IBM ADCD z/OS 1.11 lab system.

The lab reviewed RACF class configuration and searched for profiles in `OPERCMDS`, `JESJOBS`, `JESSPOOL` and `SDSF`. The evidence showed no matching profiles for the tested patterns, while SDSF display commands successfully returned active address-space and JES2 spool status information.

This lab demonstrates practical mainframe security audit skills around:

- RACF general resource classes.
- JES2 and spool security concepts.
- SDSF operational visibility.
- Operator command control review.
- Evidence-based risk documentation.

The work was performed as a read-only audit. No RACF or JES2 configuration changes were made.
