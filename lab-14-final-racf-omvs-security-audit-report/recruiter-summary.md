# Recruiter Summary

Completed a structured RACF / OMVS security audit on an IBM ADCD z/OS 1.11 environment running under Hercules.

The work covered:

- RACF global options and class status;
- privileged user and group review;
- started task identity mapping;
- OMVS segment and UID(0) review;
- sensitive system dataset checks;
- zFS backing dataset review;
- SAF classes including FACILITY, UNIXPRIV, SERVAUTH, OPERCMDS, JESJOBS, JESSPOOL and SDSF;
- SMF/audit/accountability baseline;
- JES2/SDSF operational authority review;
- APF, PROGRAM and LINKLIST authorized library review;
- final risk register and hardening roadmap.

The final outcome is a defensible audit-style portfolio showing practical RACF security analysis, evidence collection, risk interpretation and remediation planning.
