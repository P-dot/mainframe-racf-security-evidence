# Lab 32 Commands

## Controlled LISTRING delegation

```text
PERMIT IRR.DIGTCERT.LISTRING CLASS(FACILITY) ID(H7USER) ACCESS(READ)
SETROPTS RACLIST(FACILITY) REFRESH
RACDCERT ID(H7USER) LISTRING(*)
```

## Authorization rollback

```text
PERMIT IRR.DIGTCERT.LISTRING CLASS(FACILITY) ID(H7USER) DELETE
PERMIT IRR.DIGTCERT.ADDRING CLASS(FACILITY) ID(H7USER) DELETE
PERMIT IRR.DIGTCERT.DELRING CLASS(FACILITY) ID(H7USER) DELETE

RACDCERT ID(H7USER) LISTRING(*)
SETROPTS RACLIST(FACILITY) REFRESH
RACDCERT ID(H7USER) LISTRING(*)
```

The pre-refresh LISTRING was retained because it demonstrated stale RACLIST authority. The post-refresh request restored `IRRD101I`.

## Structural rollback and verification

```text
RDELETE FACILITY IRR.DIGTCERT.ADDRING
RDELETE FACILITY IRR.DIGTCERT.DELRING
SETROPTS RACLIST(FACILITY) REFRESH

RLIST FACILITY IRR.DIGTCERT.ADDRING ALL
RLIST FACILITY IRR.DIGTCERT.DELRING ALL
```

Final verification returned `ICH13003I ... NOT FOUND` for both temporary profiles.
