# Evidence

The DOCX files in this directory contain the captured 3270/ISPF command evidence used during Lab 32.

They demonstrate the complete sequence: LISTRING delegation, ADDRING denial and authorization, LAB32RING verification, DELRING denial and authorization, object cleanup, ACL rollback, RACLIST refresh behavior, final denial, structural profile deletion, and final `NOT FOUND` verification.

Before publication, review embedded screenshots for credentials, IP/MAC addresses, host identifiers, terminal/session identifiers, certificate/private-key material, and unrelated sensitive information.
