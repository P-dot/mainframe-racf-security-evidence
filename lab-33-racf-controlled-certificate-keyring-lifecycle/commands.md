## Certificate authorization and generation
```text
RDEFINE FACILITY IRR.DIGTCERT.GENCERT UACC(NONE)
PERMIT IRR.DIGTCERT.GENCERT CLASS(FACILITY) ID(H7USER) ACCESS(CONTROL)
SETROPTS RACLIST(FACILITY) REFRESH
RLIST FACILITY IRR.DIGTCERT.GENCERT ALL
```
Initial H7USER GENCERT was denied:
```text
RACDCERT ID(H7USER) GENCERT SUBJECTSDN(CN('RACF Lab 33 Synthetic Server')) WITHLABEL('LAB33CERT') SIZE(2048)
```
Investigation and additional delegation:
```text
RLIST FACILITY IRR.DIGTCERT.ADD ALL
RLIST FACILITY IRR.DIGTCERT.GENREQ ALL
RLIST FACILITY IRR.DIGTCERT.LIST ALL
RDEFINE FACILITY IRR.DIGTCERT.ADD UACC(NONE)
RDEFINE FACILITY IRR.DIGTCERT.GENREQ UACC(NONE)
PERMIT IRR.DIGTCERT.ADD CLASS(FACILITY) ID(H7USER) ACCESS(UPDATE)
PERMIT IRR.DIGTCERT.GENREQ CLASS(FACILITY) ID(H7USER) ACCESS(UPDATE)
SETROPTS RACLIST(FACILITY) REFRESH
```
H7USER repeated GENCERT. IBMUSER verified:
```text
RACDCERT ID(H7USER) LIST
RACDCERT ID(H7USER) LISTRING(*)
```

## Ring lifecycle
```text
RDEFINE FACILITY IRR.DIGTCERT.ADDRING UACC(NONE)
PERMIT IRR.DIGTCERT.ADDRING CLASS(FACILITY) ID(H7USER) ACCESS(UPDATE)
SETROPTS RACLIST(FACILITY) REFRESH

```
H7USER:
```text
RACDCERT ID(H7USER) ADDRING(LAB33RING)

```
The second command was denied. IBMUSER verified the ring. Then:
```text
PERMIT IRR.DIGTCERT.LISTRING CLASS(FACILITY) ID(H7USER) ACCESS(READ)
SETROPTS RACLIST(FACILITY) REFRESH
```
