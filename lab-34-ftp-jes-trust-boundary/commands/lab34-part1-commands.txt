PHASE 1 - DISCOVER TCP/IP PORT CONFIGURATION

/D TCPIP,,NETSTAT,PORTLIST

Purpose:
Identify configured TCP port ownership and locate the FTP service.

Interpretation:
PORTLIST represents configured/reserved port relationships. It does not,
by itself, prove that an application is currently listening.

----------------------------------------------------------------------
PHASE 2 - VALIDATE THE RUNTIME LISTENER

/D TCPIP,,NETSTAT,CONN

Purpose:
Distinguish configured ports from active runtime endpoints.

Observed relevant result:
FTPD1  0.0.0.0..21  LISTEN

Interpretation:
FTPD1 has an active TCP/21 listening socket. The shown bind scope is not
proof of reachability from every external network.

----------------------------------------------------------------------
PHASE 3 - IDENTIFY THE FTP ADDRESS SPACE

/D A,FTPD1

Purpose:

Observed relevant state:

Important:

----------------------------------------------------------------------
PHASE 12 - ATTEMPT FTP-TO-JES HANDOFF

put 'H7USER.JCL.LAB(FTPJES1)'

Observed server responses included:

125 Sending Job to JES internal reader FIXrecfm 80
250-It is known to JES as JOB07414
250 Transfer completed successfully.

Interpretation:
The FTP server accepted the stream and handed it to the JES internal reader.
The assigned job identifier proves JES ingress, not successful execution.
