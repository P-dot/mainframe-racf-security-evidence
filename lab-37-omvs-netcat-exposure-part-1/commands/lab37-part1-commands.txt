PHASE 8 — WINDOWS LOOPBACK DRIVER VALIDATION

  -Path C:\Windows\INF\netloop.inf \
  -Pattern "KM-TEST","MSLOOP"

*MSLOOP
Microsoft KM-TEST Loopback Adapter

----------------------------------------------------------------------
PHASE 9 — HERCULES LCS STATE

Hercules console:

devlist 0E20
devlist 0E21

Observed:
LCS pair present.
Base device initially busy.

----------------------------------------------------------------------
PHASE 10 — CONTROLLED z/OS STOP

z/OS console:

V TCPIP,,STOP,LCS1

D TCPIP,,NETSTAT,DEVLINKS

Result:
VARY STOP completed successfully.

----------------------------------------------------------------------
PHASE 11 — HERCULES REINITIALIZATION RETRY

Hercules console:

devinit 0E20 -n <HOST_NIC_SELECTOR> <ZOS_IP>

Observed:
HHCTU005E Invalid net device name specified
HHCLC008E ioctl error on device : Bad file descriptor

----------------------------------------------------------------------
PHASE 12 — RESTORE z/OS LCS STATE

z/OS console:

V TCPIP,,START,LCS1

D TCPIP,,NETSTAT,DEVLINKS
D TCPIP,,NETSTAT,HOME
D TCPIP,,NETSTAT,ROUTE

Result:
VARY START completed successfully.
External host reachability was still unavailable.
